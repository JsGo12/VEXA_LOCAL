# VEXA Local

Aplicación de escritorio local para organizar expedientes jurídicos y consultar documentos con RAG.

## Versión actual

El código de la versión actual está en [`VexaApp/`](VexaApp/):

- [Guía de instalación, ejecución, pruebas y empaquetado](VexaApp/README.md)
- [Alcance local y protocolo de comprobación de red](VexaApp/README_RED_LOCAL.md)

Usa Electron, Flask, SQLite y Ollama. El backend escucha en `127.0.0.1`; los datos locales se guardan en `%USERPROFILE%\.vexa_local`. Es un prototipo académico: usa documentos ficticios, no expedientes reales ni datos personales.
