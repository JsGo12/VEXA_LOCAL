VEXA LOCAL - COMANDOS PARA CORRER EL PROYECTO
==============================================
Todos los comandos son para PowerShell en Windows. Antes de cada bloque, entra a la carpeta codigo:

    cd C:\Users\titos\OneDrive\Desktop\capstone\VEXA_LOCAL-Desktop\codigo

(Si el proyecto está en otra ruta, cambia la ruta por la tuya.)


1. ENTRAR Y SALIR DEL ENTORNO VIRTUAL (.venv)
---------------------------------------------
Entrar:
    .\.venv\Scripts\Activate.ps1

    Si PowerShell dice que "la ejecución de scripts está deshabilitada", ejecuta UNA vez:
    Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
    y vuelve a intentar.

Sabrás que entraste porque la línea empieza con (.venv). Dentro del .venv puedes escribir
"python" en vez de ".\.venv\Scripts\python.exe" en todos los comandos de abajo.

Salir:
    deactivate

En cmd (Símbolo del sistema) en vez de PowerShell:
    .venv\Scripts\activate.bat


2. PRIMERA VEZ (instalar todo)
------------------------------
    python -m venv .venv                                              # crea el .venv (solo si no existe)
    .\.venv\Scripts\python.exe -m pip install -r requirements.txt     # dependencias de Python
    .\.venv\Scripts\python.exe backend\scripts\init_env.py            # crea el .env (no sobrescribe uno existente)
    ollama pull llama3.2:1b                                           # modelo de chat
    ollama pull bge-m3                                                # búsqueda por significado


3. SERVIDOR (terminal 1, déjala abierta)
----------------------------------------
Revisar la configuración sin iniciar nada:
    .\.venv\Scripts\python.exe backend\run.py --check

Iniciar el servidor (Waitress):
    .\.venv\Scripts\python.exe backend\run.py

    - En este PC: http://127.0.0.1:5000
    - Otros PCs por Tailscale: http://<IP de Tailscale>:5000   (la IP se ve con: tailscale ip -4)
    - Detenerlo: Ctrl+C en esa terminal.
    - Si dice "Ya hay un servidor VEXA activo", cierra la app de escritorio (Electron) o el otro
      servidor y vuelve a intentar.
    - Si dice que no encontró la IP de Tailscale: inicia sesión en Tailscale, o en el .env pon
      TAILSCALE_ENABLED=false para usarlo solo en este PC.

Modo desarrollo (solo este PC, recarga más simple para programar):
    .\.venv\Scripts\python.exe backend\run.py --dev


4. APLICACIÓN DE ESCRITORIO (terminal 2)
----------------------------------------
    cd desktop\electron

Primera vez (instala Electron y abre la app):
    .\setup-dev.ps1

Las siguientes veces:
    corepack pnpm start

    - Si el servidor del paso 3 ya está corriendo, la app se conecta a él.
    - Si no, la app inicia su propio servidor solo para este PC (sin Tailscale).
    - También puedes usar el navegador en vez de la app: http://127.0.0.1:5000


5. PRUEBAS
----------
    .\.venv\Scripts\python.exe -m pytest -q backend\tests                          # todas
    .\.venv\Scripts\python.exe -m pytest -q backend\tests\test_permissions.py      # un archivo


6. RESPALDOS Y CLAVE DE RECUPERACIÓN
------------------------------------
Crear la clave de recuperación (UNA vez, guarda el archivo en una USB):
    .\.venv\Scripts\python.exe backend\scripts\clave_recuperacion.py E:\vexa-clave.vexakey

Respaldo manual (el servidor ya hace uno automático cada 24 h):
    .\.venv\Scripts\python.exe backend\scripts\backup_vexa.py create E:\RespaldosVEXA\vexa-manual.vexabackup

Restaurar (con el servidor y la app CERRADOS):
    .\.venv\Scripts\python.exe backend\scripts\backup_vexa.py restore ARCHIVO.vexabackup --replace
    En otro PC agrega:  --clave-recuperacion E:\vexa-clave.vexakey


7. ÚTILES
---------
    tailscale ip -4                       # IP de este PC en Tailscale
    ollama list                           # modelos instalados
    git pull                              # traer los cambios del equipo (desde la carpeta del repo)
    corepack pnpm install --frozen-lockfile   # (en desktop\electron) si cambió package.json
